# مكتبة النماذج — رفع STL وجولة داخلية

موقع ثابت (Static) بملف واحد. ما يحتاج باك-إند ولا قاعدة بيانات ولا أي تنصيب.

## المحتويات

    index.html          الموقع كامل — البنل + المشاهد
    admin.html          لوحة الرفع على GitHub (لا ترفعها للعامة)
    models.json         قائمة النماذج الدائمة المستضافة معك
    models/             مجلد ملفات STL — كل منزل بمجلد لحاله
      villa/            بيت طابقين، 4 طبقات ملوّنة
        walls.stl
        lighting.stl
        power.stl
        boxes.stl
      single-storey/    بيت طابق واحد، طبقة وحدة
        house.stl

## التشغيل محلياً

لا تفتح index.html بالنقر المزدوج — المتصفح راح يمنع قراءة models.json.
شغّل سيرفر محلي بسيط:

    python3 -m http.server 8080

ثم افتح: http://localhost:8080

## الرفع على استضافة مجانية

### Netlify Drop — الأسرع
1. افتح app.netlify.com/drop
2. اسحب مجلد الموقع كامل (مو الملفات لحالها)
3. يعطيك رابط فوراً

### Cloudflare Pages — الأسرع بالعراق
1. حساب مجاني على dash.cloudflare.com
2. Workers & Pages → Create → Pages → Upload assets
3. ارفع المجلد

### GitHub Pages
1. ريبو جديد، ارفع الملفات بالجذر
2. Settings → Pages → Branch: main → Save
3. الرابط: username.github.io/repo-name

### Vercel
1. vercel.com → Add New → Project
2. اربطه بريبو GitHub أو استخدم `npx vercel` من المجلد

### Surge.sh — من التيرمنال
    npm install -g surge
    cd هذا-المجلد
    surge

كلها مجانية بالكامل للمواقع الثابتة، ومع شهادة HTTPS.

## الألوان — كيف تخلي كل دائرة بلون

STL ما يخزّن الألوان إطلاقاً. الحل: **صدّر كل دائرة بملف STL منفصل**،
والموقع يلوّنها هو.

ببلندر: اختر كائنات الإنارة فقط، ثم File → Export → STL وفعّل
**Selection Only**. كرّرها لكل دائرة:

    walls.stl      الحيطان
    lighting.stl   الإنارة
    power.stl      الباور
    data.stl       الداتا

**مهم:** كل الملفات لازم تتصدّر بدون تحريك أي شي بينها، حتى تبقى
متطابقة بالمكان.

بعدين بالبنل اختر كل الملفات مرة وحدة — الموقع يعطي كل ملف لون
حسب اسمه تلقائياً.

## تنظيم المنازل — مجلد لكل بيت

كل منزل يأخذ مجلد لحاله داخل models/ :

    models/
      villa-karrada/
        walls.stl
        lighting.stl
        power.stl
      beit-mansour/
        walls.stl
        lighting.stl

وبملف models.json تكتب اسم المجلد مرة وحدة بحقل `folder`،
وأسماء الملفات تبقى مختصرة:

    {
      "id": "m_karrada",
      "name": "بيت الكرادة",
      "folder": "villa-karrada",
      "unit": 1,
      "parts": [
        { "name": "حيطان", "file": "walls.stl",    "color": "#d9d5cc", "structure": true },
        { "name": "إنارة", "file": "lighting.stl", "color": "#ff5a45" },
        { "name": "باور",  "file": "power.stl",    "color": "#3d8bff" }
      ]
    }

بهذي الطريقة تكدر تسمّي ملفات كل البيوت `walls.stl` بدون أي تضارب.

إذا كتبت مسار كامل بحقل `file` (يبدأ بـ models/ أو http)، يُستخدم
مثل ما هو ويُتجاهل حقل folder — مفيد للملفات المستضافة برّه.

`structure: true` تعني إن هذي الطبقة هي الحيطان — زر «شفاف»
يذوّبها ويخلي التأسيس يبين من خلالها.

بالمشاهد يطلعلك شريط أزرار بأعلى الشاشة، كل زر يشعّل ويطفي دائرة.

## لوحة الرفع التلقائي (admin.html)

بدل ما ترفع الملفات يدوياً وتعدّل models.json، افتح admin.html.
تسحب مجلد البيت، وهي تسوي كل شي بكومِت واحد.

### التحضير مرة وحدة

1. github.com/settings/personal-access-tokens → **Generate new token**
   → Fine-grained
2. Repository access → Only select repositories → اختر ريبو الموقع
3. Repository permissions → **Contents: Read and write**
4. Generate، وانسخ التوكن (يظهر مرة وحدة فقط)
5. افتح admin.html، املأ اسم المستخدم والريبو والتوكن،
   اضغط **افحص الاتصال** ثم **احفظ الإعدادات**

### كل مرة تضيف بيت

1. رتّب الملفات بمجلد بجهازك:

        beit-karrada/
          walls.stl
          lighting.stl
          power.stl

2. اسحب المجلد على اللوحة
3. راجع الألوان (تنحدد من أسماء الملفات، وتكدر تغيّرها من القائمة)
4. اكتب اسم البيت واختر الوحدة
5. **ارفع على GitHub** — ترفع الملفات وتضيف المدخل لـ models.json
   وتسوي كومِت واحد، وتعطيك الرابط الجاهز

إذا رفعت نفس المجلد مرة ثانية، يستبدل المدخل القديم بدل ما يكرره.

### تنبيه أمني

التوكن ينحفظ بمتصفح جهازك (localStorage) وما ينرسل إلا لـ GitHub.
مع ذلك **لا ترفع admin.html على الاستضافة العامة**. خلّها بجهازك
وشغّلها محلياً:

    python3 -m http.server 8080
    # ثم افتح http://localhost:8080/admin.html

أو احذفها من المجلد قبل الرفع على الاستضافة.

## كيف تضيف نموذج بشكل دائم

النماذج اللي ترفعها من البنل تنحفظ بمتصفح جهازك فقط (IndexedDB)،
يعني الرابط ما يشتغل عند شخص ثاني. لتخليه دائم:

1. حط ملف STL بمجلد `models/`
2. افتح `models.json` وأضف سطره:

        {
          "id": "m_house2",
          "name": "بيت الكرادة",
          "file": "models/house2.stl",
          "unit": 1
        }

   * `id` لازم يبدأ بـ `m_` ويكون فريد
   * `unit`: 1 للمتر، 0.01 للسنتيمتر، 0.001 للمليمتر

3. ارفع الملفات على الاستضافة مرة ثانية

اختصار: بالبنل، تحت كل نموذج محلي اكو زر **JSON** ينسخلك السطر جاهز.

    شبكي  → يوري المضلعات
    قص    → يقطع السقف حتى تشوف الداخل من فوق

## ملاحظات فنية

* الملفات الكبيرة: استخدم تبويب «من رابط خارجي» وحط رابط مباشر
  (GitHub Raw أو Cloudflare R2). السيرفر لازم يسمح CORS.
* STL ما يخزّن الوحدة ولا الألوان. للنماذج الملوّنة بمسارات
  التأسيس، الأفضل تصدير GLB من بلندر — يحتاج تعديل بسيط بالمشاهد.
* التصادم يشتغل بالـ Raycasting على الشبكة مباشرة. إذا كان الموديل
  ثقيل جداً (فوق ٥٠٠ ألف مثلث) وصار بطيء، اضغط F لتطفي التصادم.
